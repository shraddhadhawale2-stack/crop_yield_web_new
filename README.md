# 🌱 CropVision AI

CropVision AI is a Machine Learning based web application that predicts crop yield using agricultural and environmental data.

## 🚀 Features

- Crop yield prediction using Machine Learning
- Agricultural and environmental data inputs
- Flask-based web application
- Simple and responsive user interface
- Real-time prediction results

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- Joblib
- HTML
- CSS
- JavaScript
